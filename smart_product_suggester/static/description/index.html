Smart! Product Suggester

This module allows you to suggest products to your customers on their purchase behaviour

Features
  • It uses Data Mining and Learning Techniques for analysis the customer purchase behaviour or patterns
  • It will suggest the products to the customer, that were purchased together most frequently
  • Allows you to control the suggested products by providing you some configuration settings

Sample demonstration how it works :

1. Creating new Sale Order:
  • New Sale Order is created and products are added in the order line
  • Click the button to check the suggested products
2. Suggested Products:
  • After clicking the button this pop-up will appear listing suggested products if any
  • These suggested products are suggested by the previous sales where one product is associated with other product
  • For e.g. Most customers prefer to buy T-Shirts when they are buying Trousers
  • Here we suggest for T-Shirts
3. Adding Suggested Product:
  • You can add the suggested products to Order Line by setting the required quantity of that product
  • If do not want to add, Don't Change or set the quantity for that product
  • If not interested in any suggested products, simply click the cancel
4. Updated Sale Order:
  • After adding the suggested product the sale order line is updated with that product
5. Suggested Product Configurations:
  • Under the Sales Configuration --> Settings there is a block for Suggested Products Configuration
  • Here by clicking the Update Knowledge Base button you can update the Suggestion Model
  • Updated Model gives better results but no need to update very frequently.
  • Set the parameters to control the suggestions
