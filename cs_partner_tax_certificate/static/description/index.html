Constancia SAT para Contactos de Odoo

Crea y actualiza contactos a partir de la Constancia de Situación Fiscal del SAT

Este módulo permite capturar información fiscal mexicana directamente desde la Constancia de Situación Fiscal en PDF, reduciendo errores manuales y acelerando el alta de clientes y proveedores en Odoo.

Características principales

  • Importación de Constancia de Situación Fiscal en PDF.
  • Extracción automática de RFC.
  • Extracción de nombre o razón social.
  • Extracción de código postal fiscal.
  • Extracción de domicilio fiscal.
  • Extracción de régimen fiscal.
  • Lectura de URL oficial de verificación del SAT desde el código QR.
  • Creación de contactos nuevos en Odoo.
  • Actualización de contactos existentes.
  • Validación para evitar duplicados por RFC.

Flujo de uso

  1. El usuario abre la opción para importar una Constancia SAT.
  2. Selecciona el archivo PDF de la Constancia de Situación Fiscal.
  3. El módulo analiza el documento y extrae los datos fiscales.
  4. El usuario revisa la información antes de confirmar.
  5. Odoo crea o actualiza el contacto correspondiente.

Consulta al SAT

Cuando el PDF contiene un código QR válido, el módulo puede utilizar la URL oficial incluida en la constancia para consultar la información disponible en el portal del SAT.

El módulo no envía el PDF a servidores de Cusoft. La consulta se realiza desde el servidor de Odoo hacia el dominio oficial del SAT: siat.sat.gob.mx.

Antes de cada consulta en línea, el usuario debe confirmar un aviso de consentimiento en el asistente de actualización.

Requisitos técnicos

  • Odoo 18 Community o Enterprise.
  • Módulo Contactos instalado.
  • Dependencias Python: PyPDF2, PyMuPDF, pyzbar, Pillow, beautifulsoup4, requests, certifi, truststore.
  • Librería del sistema libzbar0 para lectura de códigos QR con pyzbar (Linux: sudo apt install libzbar0).

Limitaciones conocidas

  • La extracción depende del formato del PDF emitido por el SAT.
  • Si el SAT cambia el diseño del documento, puede requerirse una actualización del módulo.
  • La consulta en línea depende de la disponibilidad del portal del SAT.
  • La lectura del código QR requiere que las dependencias del sistema estén correctamente instaladas.
